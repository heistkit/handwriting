# Handwrite — https://handwritingfont.vercel.app
#
# Everything is open. This is worth stating rather than leaving to the default,
# because the usual reason a site restricts crawlers is to protect what its
# users put into it — and there is nothing here to protect. No handwriting, no
# photograph and no font ever reaches this server; the app builds them in the
# visitor's own browser and the network is used only to fetch the app's own
# code. What a crawler can see is the same page any visitor sees, and that page
# is the pitch.
#
# /src/ and /styles.css are deliberately not blocked. A renderer that cannot
# fetch the modules sees an empty shell, and blocking them is the most common
# way a site accidentally hides itself from the one crawler that would have
# rendered it properly.

User-agent: *
Allow: /
